# Vision Board for Students 2027

Free printable classroom kit for a 2027 vision board lesson: one student worksheet on an A4 / US Letter sheet (a word for 2027, four goal boxes with a picture and a proof line, one first step with a date, and a QR code to a free phone version), a 45-minute lesson plan, questions to read aloud, a note for parents and tips for grades 3-12.

**Live page:** https://pittner.github.io/vision-board-for-students/

- Print from the browser or download SVG / PNG (A4 at 200 dpi)
- No signup, no e-mail, MIT licensed
- Digital version: the [free vision board maker](https://visionboard.bemooore.com/free-vision-board-maker/?mode=wallpaper&utm_source=github_readme&utm_medium=referral&utm_campaign=classroom_kit_2027) makes a 1080x1920 lock-screen image in the browser, no account, nothing uploaded

Rebuild: `pip install segno && python3 build.py`
